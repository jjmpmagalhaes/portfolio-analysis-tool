# Ideias para avaliar

Este ficheiro reúne possibilidades de evolução.
Antes de aprovar uma ideia, confirmar o que já existe no Excel,
a sua utilidade e os dados necessários.

## 1. Recolha assistida de factsheets

Localizar documentos oficiais através do ISIN e organizar
fontes e datas. Os dados extraídos passam por revisão
antes de serem utilizados.

## 2. Sobreposições entre fundos

Identificar emitentes ou posições subjacentes presentes
em vários fundos e estimar a exposição agregada.
Mostrar a cobertura dos dados usados na análise.

## 3. Comparação entre datas

Comparar duas fotografias da carteira para perceber
alterações nos pesos, na alocação e na concentração.
Distinguir movimentos de mercado e fluxos quando existirem
dados suficientes.

## 4. Automatização do relatório executivo

Gerar um relatório de várias páginas a partir dos dados
validados, aproveitando o relatório A4 já existente.

## 5. Simulação de alterações à carteira

Comparar a carteira atual com uma composição hipotética:
pesos, concentração, alocação e impacto no cenário de stress.

## Como escolher uma ideia

Para passar uma ideia para o ROADMAP.md, definir:

- Que problema resolve.
- Que benefício traz ao utilizador.
- Que dados e fontes exige.
- Como vamos verificar se funciona.
